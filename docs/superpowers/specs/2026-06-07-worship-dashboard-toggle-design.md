# 服事公佈欄首頁 (index.html) 雙視圖切換與黑曜石表格設計規格

此文件描述將服事公佈欄（`index.html`）升級為「雙視圖一鍵切換（預設卡片）」並重置傳統表格設計（方案 3）的開發規格。

## 1. 視覺與功能目標 (Visual & Functional Goals)
- **雙視圖一鍵切換 (View Switcher)**：
  - 於首頁季度選擇欄位旁，新增毛玻璃質感的切換按鈕組：`[📱 玻璃卡片]` 與 `[📊 傳統表格]`。
  - **預設為玻璃卡片視圖**。
  - 用戶點選按鈕後，頁面不重整，而是即時切換視圖元件（無縫過渡）。
- **「傳統表格」視覺重新設計 (Redesigned Table - Scheme 3)**：
  - **黑曜石表頭**：表頭 (`<th>`) 採用半透明黑曜石底色 `rgba(33, 37, 41, 0.92)` 搭配 `backdrop-filter: blur(8px)`，文字為白色，底部有一條 2.5px 粗的 Portal Blue (`#30759f`) 裝飾邊線。
  - **字體放大**：將表頭字體設為 `0.95rem`，內容單元格設為 `0.92rem`，確保卓越的可讀性。
  - **同工與曲目徽章化**：表格內的同工名字全部膠囊化（正常同工為 `#e6f0f7` 底搭配 `#30759f` 藍字，待定崗位為 `#fdf3e9` 底搭配 `#b25e00` 橘字）；曲目也轉化為獨立的音樂標籤（`.song-badge-item`）。
  - **請假警示行整合**：有同工請假的日程行底色微調為淡淡的黃色 `rgba(255, 243, 205, 0.3)`，與背景有明顯區別。而在日期右側/下方展示黃橙色的警告標籤（`⚠️ 警示內容`），完美整合。

## 2. 變更詳情 (Proposed Changes)

### 2.1 apps/LKC_worship/style.css
- 新增切換按鈕樣式。
- 新增方案 3 表頭樣式（`.header-style-3 th`）與大字體表格樣式（`.mock-table` 與相關子元素字體放大）。
- 微調有請假行的表格底色樣式。

### 2.2 apps/LKC_worship/index.html
- 在季度查詢欄內側右邊，新增切換視圖按鈕組。
- 新增 Table 視圖的容器 `#dashboardTableContainer`，與 Cards 視圖的容器 `#dashboardCardsContainer`，兩者放在 `#dashboardContainer` 中。

### 2.3 apps/LKC_worship/script.js
- 維持一個全域狀態 `currentViewMode = 'cards'`。
- 新增 `switchView(mode)` 函數，切換容器的顯示與隱藏，並記錄目前視圖狀態。
- 將 `renderDashboardTable` 改寫：它將會根據數據渲染生成兩種結構，分別填充進各自的容器中，以便隨時切換。

## 3. 驗證計劃 (Verification Plan)
- **切換按鈕驗收**：確認點擊「傳統表格」與「玻璃卡片」時，能夠即時、流暢地無縫切換。
- **方案 3 標題列視覺檢查**：確認表頭背景為黑曜石黑，底邊為 Portal Blue 藍色，且字體加大，可讀性高。
- **警示對比度檢查**：確認有請假的日程行背景為淡黃色，警語標籤為黃橙色，與背景具有明顯對比且沒有穿透重疊。
